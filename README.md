Weather App
A simple Weather App built using Node.js that allows users to check the current weather of any city.

Features
- Search weather by city name
- Displays temperature and weather conditions
- Clean and responsive UI
- Uses a weather API for real-time data

Tech Stack
- Node.js
- Express.js
- HTML
- CSS
- JavaScript

Project Structure
Weather-App/
──> public/
──> .env.example
──> .gitignore
──> package.json
──> package-lock.json
──> server.js
──> README.md

Installation

Clone the repository

bash
git clone https://github.com/anshsingh181730-ops/Weather-App.git

Go to the project folder

cd Weather-App

Install dependencies

npm install

Create a `.env` file and add your Weather API key.

Start the server

bash
npm start
